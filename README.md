# 航空标准分类系统

按「数据体检 → 待分类目录 → 执行分类 → 结果复核」四步完成标准目录分类，并导出可复核的 Excel 结果表。

## 启动

前置条件：

- Anaconda/Miniconda，环境名 `CF`；
- Node.js 18 及以上；
- `CF` 环境已安装 `backend/requirements.txt` 中的依赖。

双击根目录的 `start.bat`。脚本会：

1. 激活 conda 环境 `CF`；
2. 在 `backend` 启动 FastAPI，端口 `8000`；
3. 在 `frontend` 启动 Vite，端口 `5173`；
4. 自动打开 `http://127.0.0.1:5173`。

关闭两个服务窗口即可停止。修改后端代码后需要重启后端窗口。

手动启动：

```bat
conda activate CF
cd backend
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

```bat
cd frontend
npm run dev -- --host 127.0.0.1
```

## 使用流程

### 第 1 步：上传并体检已分类国标表

上传包含分类结果的 Excel（默认读取 `标准分类总表` 工作表，支持常见列名别名）。

界面会直接展示：

- 每个选用专业名称下有多少条标准；
- 每个专业的选用系统名称与完整标准号清单；
- 相同的标准号 + 相同的标准名称，但选用专业名称/系统名称不一致的数据组数与行数。

分类分布和数据体检明细都通过弹窗查看，弹窗内支持关键词搜索、每页条数切换和翻页，适合上千/上万条参照表数据。

这类问题数据会**整组排除**，不进入训练集。界面同时列出同名不同标准号、同标准号不同名称、完全重复记录、缺少字段等情况。

### 第 2 步：上传待分类目录

上传需要判断的标准清单。系统按「标准号 + 标准名称」归并：

- `GB/T` 与 `GB` 写法视为同一标准号；
- 同名不同号、同号不同名、缺少标准号/名称的数据标记为**人工分类**，不调用模型；
- 同号同名但主营单位不同的数据仍按一条标准自动分类，并标记**待确认**；
- 每个原始行都会保留，导出时逐行回填，不会因为归并丢数据。

界面会明确显示：原始行数、归并后的标准条数、自动分类条数、人工分类条数、多单位待确认条数，以及归并口径。

### 第 3 步：执行分类

只对无歧义的标准调用模型；人工分类数据留空，等待用户在结果页选择专业。分类完成后自动进入结果表。

### 第 4 步：复核并导出

结果表分为「自动分类」和「人工分类」两个视图：

- 自动分类可以逐条修改专业、查看低置信度、确认多单位标准；
- 人工分类必须由用户选择所属专业名称，不提供模型猜测；
- 支持搜索、按专业筛选、只看待复核/待确认。

导出时直接打开**原始待分类 Excel**，在末尾追加两列：

- `所属专业名称`：模型结果或人工选择；
- `置信度`：自动分类写模型置信度，人工分类写 `人工`；未完成人工分类的写 `待人工`。

原始工作表、列和所有行全部保留；同一标准的重复行、多单位行都会回填相同结果。

## 数据体检规则

参照表读取后会检查：

- 相同标准号 + 相同标准名称，但选用专业/系统不一致 → **问题数据**，整组排除训练集；
- 同名不同标准号、同标准号不同名称 → **提示**；如果专业一致，通常只是版本或叫法差异，不影响训练；只有分类不一致时才升级为需处理；
- 完全重复记录 → 提示并合并；
- 一个专业对应多个系统 → 提示，系统名称按多数票确定；
- 缺少标准名称 / 选用专业名称 / 选用系统名称 / 标准号 → 提示，相关行不参与训练。

分类类别完全由上传的参照表决定，不再写死固定分类。
